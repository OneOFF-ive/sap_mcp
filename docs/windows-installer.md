# SapLink Windows 安装指南

本指南面向使用安装包的用户，不需要下载源码或安装开发工具。安装包、快捷方式统一使用 SapLink 名称；配置与安装标识见 [命名与本地数据](local-data.md)。

## 安装前准备

- 电脑运行 64 位 Windows 10（1809 或更新）或 Windows 11。
- Intel / AMD 电脑选择 `SapLink-0.1.0-win-x64-setup.exe`；Windows ARM 电脑选择 `SapLink-0.1.0-win-arm64-setup.exe`。
- 准备 SAP 的 ADT 地址、Client、用户名和语言；不清楚时向 SAP 管理员获取。密码稍后在本机输入。

安装包包含运行所需组件，无需另装 Node.js 或 npm。安装过程无需联网，连接 SAP 时需要相应网络。管理页面需要可用的默认浏览器。

命令行入口为 `saplink`。安装完成后重新打开终端，确保新的 PATH 生效。

## 安装应用

1. 双击与你电脑匹配的安装包。
2. 按向导选择安装位置，建议保留“加入 PATH”和“桌面快捷方式”选项。
3. 完成安装。应用仅安装给当前 Windows 用户。
4. 双击桌面的 **SapLink**，或开始菜单中的 **SapLink 管理界面**。

当前版本尚未进行发布者代码签名，Windows 可能显示“未知发布者”或 SmartScreen 提示。先确认安装包来自可信来源；不能确认来源时不要继续安装。

## 首次使用

打开后，浏览器显示本地管理页面，任务栏右下角出现托盘图标。

1. 添加 SAP 连接，在本机输入登录信息。
2. 测试连接，确认可以访问 SAP。
3. 创建 MCP 访问令牌并妥善保存。
4. 在“MCP 服务”页启动服务。
5. 按 [部署与运维手册](operations.md) 配置 AI 客户端。

默认先保持写入关闭，可以先进行读取和查询。需要开发变更时，再为目标连接启用写入。

关闭浏览器标签页不会退出应用。再次点击快捷方式或双击托盘图标可重新打开页面；通过托盘菜单 **退出 SapLink 管理** 正常退出。

## 升级与修复

应用和服务启动后自动检查正式版，运行期间每 24 小时再检查，复用 24 小时缓存。管理页面发现更新后显示下载链接；没有自动安装或强制检查按钮。可在终端执行 `saplink update check` 手动检查，需要立即刷新时使用 `--force`。检查不停止应用、不下载或安装文件；设置 `SAPLINK_AUTO_UPDATE_CHECK=0` 并重启可关闭自动检查。

检查需要联网访问 GitHub，不影响离线安装和已有 SAP 服务。没有公开正式版或网络检查失败时不能判断已是最新版。旧版本不支持该命令时，直接查看 [GitHub Releases](https://github.com/OneOFF-ive/saplink/releases)，按本机架构选择安装包。

1. 先通过托盘菜单退出应用；如果使用命令行启动服务，按 [运维手册](operations.md) 正常停止。
2. 运行新安装包，按向导在原位置升级或修复。
3. 完成后重新打开应用，测试已有连接。

升级保留连接配置等用户数据。同一 Windows 用户只安装一份应用；再次安装会使用原安装位置。需要更换位置时，先卸载再重新安装。

如果安装程序提示应用仍在运行，先正常退出后重试；不要强行删除锁文件。无法解决时查看 [故障排查](operations.md#8-常见故障)。

## 卸载

在 Windows“设置 → 应用”中找到 **SapLink**，或使用开始菜单中的卸载入口。

卸载移除应用及其快捷方式，保留连接配置、访问令牌、日志和已保存的 SAP 凭据。重新安装后可继续使用这些数据。如需清除个人数据，先查阅 [文件与备份说明](operations.md#7-文件权限与备份)，确认要保留的内容。
